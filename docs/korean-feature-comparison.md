# 영상 지적 사항·Adobe·FilmCraft 비교와 개발 우선순위

기준일: 2026-10-18. 대상: 이 Mac의 기존 공식 FilmCraft 0.5.0, 로컬 소스 0.6.0,
한국어 전사·후보 검토·Mac 한국어/영어 TTS를 포함한 수정 빌드.
Adobe 기능 설명은 공식 도움말 기준이다. 로컬 Premiere Pro 2023을 직접 실행했으나
구독/구매 창에서 막혀 편집·출력 비교는 수행하지 못했다. 사용자가 이 제한을 표시하고
결과 정리를 요청했으며 라이선스 우회·구매·체험 시작은 하지 않았다.
다른 앱 6개의 전체 기능 감사나 Adobe 전체 기능의 동등성 평가가 아니다.

현재 설치본은 후속 배포 작업에서 **0.6.0 Release Build 18**로 교체했다. 아래 빌드17의 긴 영상
새 전사 결과는 빌드17 검증 이력이다. 빌드18에서는 식별 표시·패키지 내용과 기존 10/60분 프로젝트의
실행 취소·저장·3초 내보내기를 확인했다. [설치본 검증 범위와 서명 제한](macos-release18-validation.md)을 참고한다.

## 영상이 실제로 지적한 것

원본: [영상](https://www.youtube.com/watch?v=XwY9bW2r3hU&t=723).
확보된 한국어 자동 자막 중 관련 구간만 재검토했다. 자동 자막의 오기 가능성이 있다.

| 구간 | 발언의 의미 | 개발 요구로 해석 |
|---|---|---|
| 12:03~12:09 | 전사와 TTS가 빠져 아쉽다고 설명 | 음성→텍스트와 텍스트→음성을 각각 구분해 확인 |
| 12:10~12:18 | 영상 오디오를 분석해 대사를 만드는 기능 | 한국어 자동 전사, 단어별 시각 |
| 12:18~12:27 | 대사를 분석해 무음 구간을 잘라내는 기능 | 전사 기반 쉼 구간 탐색·선택 제거 |
| 12:29~12:39 | 로드맵에 있으나 구현 시점을 모른다고 설명 | 소스 구현과 설치된 배포판의 활성 여부를 별도로 확인 |
| 12:55~13:13 | Premiere에 가까운 기능을 요구하는 의견 | 목표 의견이며 실제 기능·품질의 동등성을 입증하는 자료는 아님 |

영상의 뒤쪽 설명은 전사와 전사 기반 편집에 집중한다. TTS는 문장을 새 음성으로 만드는 별개 기능이다.
추임새 제거, 자막 번역, AI 음질 개선 등은 아래의 추가 비교 항목이며 영상이 모두 지적했다고 주장하지 않는다.

## 상태를 나누는 기준

- **검증됨**: 이 환경에서 실제 파일 또는 명시한 자동 테스트를 통과했다.
- **있음·추가 검증 필요**: 코드·명령이 있지만 실제 사용자 파일의 품질을 검증하지 않았다.
- **비활성**: 코드가 있으나 해당 배포 빌드에 포함되지 않았다. 기능 부재와 다르다.
- **오류/제약**: 구체적인 재현 결과나 소스상 한계가 있다.
- **없음**: 검토한 소스에서 대응 구현이 없고 공식 프로젝트의 gap 문서도 미구현으로 기록한다.

## 현재 설치·검증 상태

`/Applications/FilmCraft.app`와 기존 개발판에 빌드 `20261018.17`을 반영했다. 실제 새10분 전사는 창 복원 실패 뒤 같은 결과에서 후속 검사를 이어 통과했고, 새60분은 한 흐름으로 통과했다. 4.35초 왕복 지연 원인 분리는 남아 있다. 이번 전사·경계·UI 검증의 범위와 한계는 [실제 한국어 검증 보고서](real-korean-validation.md)를 따른다.
두 앱 모두 서명 검증을 통과했다. 앱 식별자별 서명 데이터는 다르지만 실행 파일의 14개 코드/데이터 섹션은 일치한다.
실행한 개발판 TTS 화면에서 English (United States) / Samantha (Mac) 기본 선택도 직접 확인했다.

한국어 전사·후보 검토·유나 TTS의 기존 실제 파일 검증을 유지한다. 영어 Samantha는 추가로
미리듣기의 프로젝트 불변, 나레이션 생성/수정, 생성과 수정 각각의 실행 취소·다시 실행,
저장·재열기, 원래 오디오를 음소거한 H.264/AAC MP4 출력을 실제 파일로 검증했다.
출력은 13.166667초 / 316프레임이며 전체 디코딩이 성공했고, 나레이션 오디오 RMS는 0.06632로 무음이 아니다.
검증 원고와 저장 파일은 테스트용이며 사용자 미디어를 수정하지 않았다.
최신 TTS UI 검사 3개(언어 전환·미리듣기/설정·생성/다시 편집/실행 취소)도 모두 통과했다.

근거: `target/verification-tts-en/report.json`, `target/verification-tts-en/edited.fcproj`,
`target/verification-tts-en/english-narration.mp4`. 이전의 빌드 대기 상태는 해소됐다.

## 개발 우선순위와 완료 조건

1. **P0 — 이번 납품**: 기존 전사 빌드 활성화, 한국어 후보 검토, Mac 한국어/영어 TTS,
   언어/목소리 선택 수정, 실행 취소·저장·재열기·H.264/AAC 내보내기 검증.
   통과 여부는 `target/verification/report.json`과 `target/verification-tts/report.json`, UI 테스트 로그로 확인한다.
2. **P1 — 구현·검증 범위와 남은 개선**: 네이티브 전사 백그라운드 작업·진행률·취소·재시도를 구현하고,
   합성 한국어 10분/60분 영상으로 UI 응답, 취소 시 프로젝트/원본 불변, 실행 취소·다시 실행,
   저장·재열기·전체 내보내기를 검증했다. 실제 면담 10/60분의 단어 경계·추임새 오탐도
   평가하고 정렬·0초 단어 삭제·고정 점수 오류를 수정했다. 후속 빌드13에서 짧은 추임새의 프레임 반올림 손실, 일반 단어가 앞 발화를 흡수하는 일부 경계 오류,
   숨겨진 UI 갱신의 입력 소비·정지된 시계를 수정했다. 같은 최종 앱에서 실제 10/60분 자료를
   각각 새로 전사해 편집·Undo/Redo·저장/재열기·전체 출력을 검증했다. **낮은 전체 후보 재현율,
   남은 인식/경계 오류와 긴 응답 대기의 원인 분리**는 후속 P1 항목이다. 빌드17의 실제 새 전사·후속 검사는 아래 절을 따른다. 빌드15에서 기본 잠금/복수 트랙 조합을 검사했으며 추가 효과·트랙 조합은 남아 있다.
3. **P2 — 실사용 범위 확대**: 음향 기반 VAD와 전사 간격 구별, 한국어 발음/숫자/영문 혼용 TTS,
   자막 생성·SRT 왕복, 번역 검토, 화자 평가, `.prproj` 가져오기, 자주 쓰는 카메라 코덱과 GPU 실측.
   사용자 영상 5~10개를 고정 평가 자료로 삼아 오류율·내보내기 결과를 비교한다.
4. **P3 — 고비용 기능**: 객체 분리/추적, 생성형 영상 연장, 플러그인 생태계.
   모델·플랫폼·교환 형식의 제약을 먼저 확인하고 별도 범위로 개발한다.

P1의 백그라운드 작업·실제 녹음 평가와 이번 안전성·UI 개선의 구현 및 검사 범위를 완료했다. 모든 후보의 자동 삭제 정확도나 UI 지연 완전 해소를 보장하지 않는다. 남은 인식·경계 오류, 재현율 개선, 추가 트랙 검사, P2~P3는 미완료 항목이다. 업스트림의 대략적인 동등성 퍼센트나
에이전트 작업시간 추정치를 이 환경에서 측정한 값처럼 사용하지 않는다.

## 사용법과 한계

`Text → Review pauses / fillers`에서 **Transcribe Korean**으로 전사하고 후보를 확인한다.
**Open Text to Speech** 또는 `Window → Text to Speech`에서 한국어·유나 또는 영어·Samantha를 고른 뒤 원고를 입력한다.
**Preview**, **Add to timeline**으로 생성하고, 타임라인 나레이션 클립을 선택하면 원고를 다시 편집할 수 있다.
`[pause 1s]`로 정확한 무음을 삽입한다. 속도와 음높이는 OS 음성 설정으로 적용하며 감정·강조의
세밀한 제어, 목소리 복제, 플랫폼 간 동일 음질은 제공하지 않는다.

Mac TTS는 고정 경로 `/usr/bin/say`만 셸 없이 실행하는 선택적 Rust 어댑터이다.
외부 실행파일·Apple 음성·Adobe 자산을 번들에 넣지 않는다. Yuna 설치가 필요하며 OS 음성 사용 조건이 적용된다.
현재 Mac의 Yuna는 설치 상태를 실제 확인했다. 파일은 비공개 임시 디렉터리에서 합성하고,
시간·파일 크기·문자 수·분절 수를 제한하며 실패를 오류로 반환한다.
한국어 전사는 로컬 CPU Whisper로 실행한다. 사용자 미디어나 원고를 클라우드에 보내지 않는다.
