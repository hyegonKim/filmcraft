## 이번 업로드 전 검사

- 포맷, 전체 release Clippy, 계층, 자산 검사 통과. 자산 69개.
- Python 검증 스크립트 구문, 패키징 셸 구문, Git 공백 검사 통과.
- 전사 테스트의 단일 Range 슬라이스 Clippy 경고 6건과 시간 측정 API 두 곳을 수정했다. 시간 측정은 프로젝트 표준인 `web_time::Instant`를 사용한다.
- 엔진 재검사: 557개 통과, 3개 제외. 백그라운드 전사 취소·재시도, 일반 단어·잠긴/복수 트랙 보존, 실행 취소 검사를 포함한다.
- 전체 workspace 테스트는 미통과다. GPU `fx_tests::gpu_effects_match_cpu_exactly`에서 `extract`의 CPU/GPU 상대 오차 약 `1.33e-4`가 검사 기준을 넘었다. 같은 GPU 그룹의 나머지 31개는 통과했다.
- `crates/gpu` 및 `crates/render`에는 이번 수정이 없다. 이 실패가 원본 커밋에서도 재현되는지는 별도로 확인하지 않았으며, 관련 없는 GPU 알고리즘이나 허용 오차를 수정하지 않았다.
- 실패 이후 남은 27개 패키지 검사도 시도했지만 높은 시스템 부하로 추가 빌드를 중단했다. 이 패키지들의 전체 검사 완료를 주장하지 않는다.
- WASM 호환성 검사: 미완료. 실행 환경의 Rust 버전 선택 문제를 해결해 Rust 1.95로 검사에 진입했지만, 높은 시스템 부하로 추가 빌드를 중단했다. WASM 통과를 주장하지 않는다.
