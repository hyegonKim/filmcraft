# FilmCraft H.265 hardware retest on RTX 4070 Ti

On 2026-11-23, the Windows FilmCraft 0.20.1 working copy on E: was rebuilt and retested with [PR #21](https://github.com/hyegonKim/ArtCraft/pull/21) applied. The GitHub merge commit was 7603d9c7. The working copy retained its existing local edits.

The application built with cargo build --locked -p filmcraft. Across the four affected packages, the locked tests reported 490 passed, zero failed, and four ignored. The optional VP8 comparison skipped its body because vpxenc was unavailable.
